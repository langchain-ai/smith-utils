# smith-utils
A collection of handy scripts and utilities for everyday development and system tasks.

## Tools

### [smith-fly](./smith-fly/README.md)
Automated installation and management tool for LangSmith and LangSmith Deployment on Kubernetes clusters. Designed for testing and development environments to quickly spin up LangSmith instances for reproduction and evaluation purposes.

### [aws-smith-fly](./aws-smith-fly/README.md)
Automates provisioning an AWS EKS cluster and deploying LangSmith on it. Designed for testing and development environments — not production.
